Privacy

Last updated: November 2026. This page describes how the software behaves. The site operator should review it before a public launch.

What stays on your device

AI-likeness scoring, word counts, file reading (.txt, .md, .docx) and offline rewriting all run in your browser. The text you enter for these features is not sent to any server.

What is sent when a language model is connected

If the site operator has connected a language model, the Humanize, Fix grammar, Simplify and Summarize tools send the passage you submit to this site’s server, which forwards it to the model provider (OpenAI or Cloudflare Workers AI) and returns the revision. The tool states which mode is active before you run it. The provider’s own retention and abuse-monitoring policies apply to text it receives.

What is stored

The application does not save your text, does not log its content, and does not use cookies, local storage, analytics or advertising scripts. Your text stays in page memory until you reload or close the tab. The hosting provider keeps ordinary request metadata such as IP address and time, which is also used to limit abusive request rates.

Your choices

Do not submit confidential or sensitive material to a model-backed rewrite. Reports, copies and downloads are created only when you choose them.

Contact

Questions and requests can be raised through the project’s issue tracker. Do not include private text in a public issue.
